<a name="english"></a>
## English

**PageAsk** is a Safari Web Extension (Manifest V3) that adds an **AI sidebar** to any
webpage. Paste your own LLM API key, and you can chat with the page — ask questions,
translate, and summarize — without copy-pasting or switching windows. It is the
**free, self-hosted version of Sider.ai**: instead of a paid subscription to a
third-party service, you connect your own model account and pay only the model's
token cost (or nothing, with free tiers).

### ✨ Features

- **Ask the page** — free-form questions with the whole page (or a selection) as context
- **One-click translate** — translate the page section-by-section, or just the selection
- **One-click summarize / explain** — quick actions, no typing needed
- **Streaming output** — token-by-token rendering with a stop button
- **⌘K shortcut** — press `Command + K` to toggle the sidebar (press again to hide)
- **Bring your own key** — DeepSeek, GLM (Z.ai / Zhipu), Kimi (Moonshot), or any
  OpenAI-compatible endpoint (one-api / new-api / vLLM / local gateway)
- **Private by design** — your API key stays in local `storage.local` (never synced,
  never uploaded); all model calls are made from the extension background, so page
  content scripts never touch your key

### 🧩 Supported providers

| Provider | Base URL | Example models | Get a key |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-v4-pro` / `deepseek-v4-flash` | [platform.deepseek.com](https://platform.deepseek.com/api_keys) |
| GLM (Zhipu) · CN | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.7` / `glm-4.6` / `glm-4-flash` | [open.bigmodel.cn](https://open.bigmodel.cn/usercenter/apikeys) |
| GLM (Z.ai) · Intl | `https://api.z.ai/api/paas/v4` | `glm-5.3` / `glm-5.3-flash` | [z.ai/model-api](https://z.ai/model-api) |
| Kimi (Moonshot) | `https://api.moonshot.ai/v1` | `kimi-k3` / `kimi-k2.6` | [platform.kimi.ai](https://platform.kimi.ai/console/api-keys) |
| Custom | any OpenAI-compatible `/chat/completions` | determined by your gateway | — |

> ⚠️ **GLM keys are site-bound**: a key issued on the CN site (open.bigmodel.cn) does
> not work on the international site (z.ai), and vice versa. Pick the site matching
> your key in the settings page.
>
> ⚠️ Model names and pricing change over time; the model field is editable and should
> follow your provider's console.

### 🚀 Install & run

**Prerequisites:** macOS 12+, Xcode (with Safari extension support). Enable
*Safari → Settings → Advanced → "Show features for web developers"*.

1. Open the Xcode project:

   ```bash
   open macos/PageAsk/PageAsk.xcodeproj
   ```

2. Pick the **PageAsk** scheme and your Mac. In *Signing & Capabilities*, select your
   own **Team** for both targets (`PageAsk` and `PageAsk Extension`). A free personal
   team works for local development.
3. Press **⌘R** to run. The app opens an onboarding page on first launch.
4. Click **"Open Safari extension settings…"**, then enable **PageAsk Extension** in
   *Safari → Settings → Extensions*.
5. Open any page, click the toolbar icon (or press **⌘K**), then open **⚙ Settings**
   in the panel and paste your API key.

> Unsigned build (CI / no developer account):
>
> ```bash
> cd macos/PageAsk
> xcodebuild -project PageAsk.xcodeproj -scheme PageAsk -configuration Debug \
>   build CODE_SIGNING_ALLOWED=NO
> ```

### 🧪 Unit tests

Pure logic (provider resolution, prompt building, SSE parsing, truncation, Markdown)
does not depend on the browser:

```bash
node --test test/
```

### 📡 Smoke-test a real key

Validate an endpoint / key / model without installing the extension:

```bash
# Key via env var (never written to disk)
PAGEASK_KEY=sk-xxxx node scripts/smoke.js deepseek
PAGEASK_KEY=sk-xxxx node scripts/smoke.js kimi
PAGEASK_KEY=sk-xxxx node scripts/smoke.js zai:cn     # GLM CN
PAGEASK_KEY=sk-xxxx node scripts/smoke.js zai:intl   # GLM Intl

# or as a positional arg
node scripts/smoke.js deepseek sk-xxxx
node scripts/smoke.js custom sk-xxxx http://127.0.0.1:8000/v1 gpt-4o-mini
```

> DeepSeek v4 models are reasoning models: thoughts are in `reasoning_content` and the
> final answer in `content`. The extension renders them separately (thoughts collapse
> into a "thinking" section).

### 🔧 Custom endpoints

Select **Custom** in settings and fill in an OpenAI-compatible Base URL, model, and
key. `http(s)://localhost/*` and `http(s)://127.0.0.1/*` are allowed by default; other
domains must be added to `host_permissions` in `web-extension/manifest.json`.

### 🔐 Privacy & security

- The API key lives only in the extension's local `storage.local` — no iCloud sync, no
  third-party upload.
- All LLM requests are made from the **background** (extension context); page content
  scripts cannot read the key.
- The current page's text (or your selection) is sent to the provider you choose. Only
  enter a key for a provider you trust.
- No browsing-history tracking; no persistent chat history in the panel.

### 🌐 Use in Chrome / Edge

`web-extension/` is standard MV3:

1. Chrome / Edge → Extensions → Developer mode → **Load unpacked** → select `web-extension/`.
2. Open the extension options and configure the same way.

### 📌 Notes

- Default content length is ~16,000 chars (adjustable 2k–200k in settings).
- The panel is an in-page floating sidebar (Shadow DOM); it does not rewrite the page DOM.
- This repository targets local development; it does not include App Store distribution
  or notarization configuration.

## 中文

**页问 PageAsk** 是一个 Safari 网页扩展（Manifest V3），给任意网页加上一个 **AI 侧边栏**。
粘贴你自己的 LLM API Key，就能直接对网页提问、翻译与总结——不用复制粘贴、不用切换窗口。
它就是 **免费、自部署版的 Sider.ai**：不再为第三方服务订阅付费，而是接入你自己的模型账号，
只付模型的 token 费用（用免费额度甚至可以零成本）。

### ✨ 功能

- **对网页提问**——以整页（或选中文字）为上下文，自由提问
- **一键翻译**——整页逐段翻译，或只翻译当前选区
- **一键总结 / 解释选区**——快速动作，无需打字
- **流式输出**——逐 token 显示，可随时停止
- **⌘K 快捷键**——按 `Command + K` 打开侧边栏，再按一次隐藏
- **自带 Key**——支持 DeepSeek、GLM（Z.ai / 智谱）、Kimi（Moonshot），以及任意
  OpenAI 兼容端点（one-api / new-api / vLLM / 本地网关）
- **隐私优先**——API Key 只保存在本机 `storage.local`（不同步、不上传）；所有模型请求
  都由扩展后台发起，网页内容脚本永远接触不到你的 Key

### 🔧 自定义端点（one-api / new-api / 本地网关）

设置页选择「自定义」并填写 OpenAI 兼容的 Base URL、模型与 Key。默认已放行
`http(s)://localhost/*` 与 `http(s)://127.0.0.1/*`；其它域名需在
`web-extension/manifest.json` 的 `host_permissions` 中手动追加。

### 🔐 隐私与安全

- API Key 仅保存在扩展本机 `storage.local`，不会同步到 iCloud、不上传第三方。
- 所有 LLM 请求由 **background（扩展上下文）** 发起；网页内的 content script 无法读取 Key。
- 提问/翻译时，当前网页的正文或选区文本会发送给你选择的服务商。请只在自己信任的服务商填写 Key。
- 不跟踪浏览历史；面板无本地对话历史持久化。

### 🌐 迁移到 Chrome / Edge

2. 在扩展详情页打开「扩展程序选项」完成同样配置。
