页问 PageAsk

用自己的 LLM API Key，对任意网页提问、翻译与总结

使用步骤

  1. 点击下方按钮，在 Safari 设置 → 扩展 中勾选启用 PageAsk Extension。
  2. 打开任意网页，点击 Safari 工具栏的 页问 图标打开右侧面板。
  3. 点击面板底部 ⚙ 设置，选择服务商（DeepSeek / GLM / Kimi / 自定义）并填入你自己的 API Key，然后「测试连接」。
  4. 回到网页即可翻译、总结或直接对当前页面提问。
